One folder per project. Each has a `STATE.md` — the single authoritative answer to
"where is this project." If it disagrees with a chat, a note, or a memory, the file wins.

**Every stage says "unknown" because nothing has been verified in this system yet —
not because no work exists.** Priority 1 is finishing and verifying existing projects,
and that cannot start until each project's real state is on record.

Each `STATE.md` ends with five intake questions. Answering them for one project is
enough to start; they do not all have to happen at once.

## Starting a new project

Copy `_TEMPLATE/STATE.md`. But first check priority 1 in `CLAUDE.md`: a new project has
to beat finishing an existing one, and "new idea" is not a reason.

## Stages

`concept` → `prototype` → `tested MVP` → `deployed` → `client deployment` → `verified result`

What may be claimed publicly at each stage is in
`business/knowledge-vault/BRAND.md`.
